# Supply Chain Inventory Analytics Dashboard

Power BI project analyzing sales, inventory, customers, suppliers, warehouses, delivery, discounts, and returns.

## About the Project

Built a Power BI dashboard using six CSV datasets. The project includes data cleaning in Power Query, DAX measures, a star-schema data model, and interactive dashboards.

The analysis covers 13 project tasks, from data validation and modeling to product, customer, supplier, delivery, and return analysis.

## Key Features

- Sales and order KPIs
- Product and customer analysis
- Warehouse and supplier performance
- Monthly sales trends
- Discount, delivery, and return analysis
- Product-level drill-through
- Executive dashboard with slicers

## Data Model

**Fact Table**
- Orders

**Dimension Tables**
- Product
- Customer
- Warehouse
- Supplier
- Date

## Tools

- Power BI Desktop
- Power Query
- DAX
- Star Schema
- CSV
